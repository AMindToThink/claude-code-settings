name: How to read paper table numbers
description: Machine-generated LaTeX tables — read results/tables/*.tex or summary_table.txt, never the PDF or memory
type: reference
---

Paper tables are machine-generated by `scripts/analyze_c_ainf.py` and `\input{}`'d by the paper. The authoritative chain:

1. **Exact paper numbers:** `results/tables/contest_rho_oca.tex` and `results/tables/dectest_rho.tex`
2. **All metrics (19 variants):** `figures/tevet_validation/c_ainf_analysis_v3/summary_table.txt`
3. **Regenerate:** `uv run python scripts/analyze_c_ainf.py --run-tag qwen25_completion_v3 --output-dir figures/tevet_validation/c_ainf_analysis_v3 --skip-fit`

When citing or discussing table numbers, always `Read` the .tex or .txt file — never rely on memory, conversation context, or PDF rendering. Cross-check any hand-written inline numbers in the paper prose against the generated tables.
