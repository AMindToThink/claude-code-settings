name: Always cite numeric sources
description: When writing numbers to files (captions, papers, reports), MUST include a reference to the deterministic source (script + output file) so other researchers can verify
type: feedback
---

When writing numbers to any important file (captions, paper, reports, documentation), ALWAYS include a reference to the source of those numbers. The source must be something other researchers can check — a deterministic script they can re-run, a log file, or an output file.

**Why:** Matthew caught me writing numbers from memory/context without citing where they came from. Some turned out to be fabricated (e.g., "a_n raw AUC = 0.856" that didn't exist in any output). Even when correct, uncited numbers can't be verified by collaborators or reviewers.

**How to apply:** Every caption, table, or report that contains numeric results must include a line like:
- "Source: `scripts/analyze_c_ainf.py` → `summary_table.txt` (ROC AUC column)"
- "Generated by: `uv run python scripts/foo.py`, output at `results/bar.json`"

If the number doesn't come from a verifiable source, don't write it. Compute it first, save it to a file, then cite that file.
